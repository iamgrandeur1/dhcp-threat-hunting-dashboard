# DHCP Threat Hunting Dashboard Using Splunk

This repository documents the creation of a DHCP threat hunting dashboard using Splunk and Zeek DHCP logs.

The project focused on transforming raw DHCP telemetry into visual operational intelligence for behavioral analysis and detection engineering workflows.

---

##  Technologies Used

- Splunk
- Zeek
- Kali Linux
- VirtualBox

---

##  Focus Areas

- Threat Hunting
- Detection Engineering
- Dashboarding
- DHCP Analysis
- SIEM Operations
- Network Visibility
